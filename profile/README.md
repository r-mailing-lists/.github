# R Mailing Lists

Complete archives of the R project's mailing lists, mirrored from the public [Mailman archives](https://stat.ethz.ch/mailman/listinfo) and updated daily. One repository per list, each holding the mbox files exactly as upstream publishes them, monthly, quarterly, or annually depending on the list, alongside a parsed, structured form, plus a combined Parquet release for analysis.

**[r-mailing-lists.thecoatlessprofessor.com](https://r-mailing-lists.thecoatlessprofessor.com/)**

## Core lists

- [r-help](https://github.com/r-mailing-lists/r-help), the main R mailing list, for problems and solutions using R
- [r-devel](https://github.com/r-mailing-lists/r-devel), code development in R
- [r-package-devel](https://github.com/r-mailing-lists/r-package-devel), help with package development
- [r-announce](https://github.com/r-mailing-lists/r-announce), major announcements about R
- [r-packages](https://github.com/r-mailing-lists/r-packages), announcements of new or enhanced contributed packages
- [r-help-es](https://github.com/r-mailing-lists/r-help-es), R help in Spanish

## Feedback

Found a message that is missing, garbled, or filed under the wrong thread? Report it at [r-mailing-lists/feedback](https://github.com/r-mailing-lists/feedback/issues/new/choose). All feedback about the archives, the data, and the site is tracked in one place.

To ask that a message or personal information be removed, read the [archive policy](https://github.com/r-mailing-lists/.github/blob/main/ARCHIVE_POLICY.md) and email us rather than opening an issue.
