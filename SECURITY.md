# Security Policy

This organization publishes mirrors of public mailing list archives. There is no private user data, there are no accounts, and there is no authentication, so most reports will concern the site, the ingestion pipelines, or the published data rather than a classic vulnerability. We still want to hear about anything that looks wrong or unsafe.

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue.

- Email [support@caffeinatedmath.com](mailto:support@caffeinatedmath.com).
- Or use GitHub's private "Report a vulnerability" button under the Security tab of the affected repository.

Include the affected repository, a description of the issue, and steps to reproduce it if you can. We will acknowledge your report as soon as we can and keep you posted on a fix. This project is maintained by one person on a best-effort basis, so please allow time for a response.

## What goes elsewhere

- Missing messages, garbled bodies, broken threading, and site bugs go to [r-mailing-lists/feedback](https://github.com/r-mailing-lists/feedback/issues/new/choose).
- Requests to remove a message or personal information go to [support@caffeinatedmath.com](mailto:support@caffeinatedmath.com). Read the [archive policy](https://github.com/r-mailing-lists/.github/blob/main/ARCHIVE_POLICY.md) first.
